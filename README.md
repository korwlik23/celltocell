# 📊 Excel Comparison Tool

เครื่องมือเปรียบเทียบไฟล์ Excel 2 ไฟล์แบบ Cell-by-Cell ด้วย Python

## ✨ คุณสมบัติ

- ✅ เปรียบเทียบไฟล์ Excel แบบ Cell-by-Cell
- ✅ ตรวจสอบความแตกต่างของขนาดไฟล์ (แถว/คอลัมน์)
- ✅ ข้าม (Ignore) ความแตกต่างที่เป็นช่องว่าง (Whitespace)
- ✅ แสดงผลลัพธ์ในหน้าจอ Console
- ✅ สร้างไฟล์รายงาน Excel สรุปความแตกต่าง

## 📦 การติดตั้ง

### 1. ติดตั้ง Dependencies

```bash
pip install -r requirements.txt
```

หรือติดตั้งแยกทีละตัว:

```bash
pip install pandas openpyxl numpy
```

## 🚀 วิธีใช้งาน

### วิธีที่ 1: ใช้ค่า Default

วางไฟล์ `file1.xlsx` และ `file2.xlsx` ไว้ในโฟลเดอร์เดียวกับ Script แล้วรัน:

```bash
python compare_excel.py
```

### วิธีที่ 2: ระบุชื่อไฟล์เอง

```bash
python compare_excel.py -f1 ไฟล์แรก.xlsx -f2 ไฟล์สอง.xlsx -o รายงาน.xlsx
```

### Options ทั้งหมด

| Option | คำอธิบาย | ค่า Default |
|--------|---------|-------------|
| `-f1`, `--file1` | พาธไฟล์ Excel ไฟล์ที่ 1 | `file1.xlsx` |
| `-f2`, `--file2` | พาธไฟล์ Excel ไฟล์ที่ 2 | `file2.xlsx` |
| `-o`, `--output` | พาธไฟล์รายงานผลลัพธ์ | `comparison_report.xlsx` |

## 🔧 การใช้งานใน Code (Import)

```python
from compare_excel import compare_excels

# เรียกใช้ฟังก์ชันโดยตรง
differences = compare_excels(
    file1_path='data_old.xlsx',
    file2_path='data_new.xlsx',
    output_path='my_report.xlsx'
)

# ตรวจสอบผลลัพธ์
print(f"พบความแตกต่าง {len(differences)} จุด")
```

## ⚠️ ข้อควรทราบ

1. **รองรับเฉพาะไฟล์ `.xlsx`** (Excel 2007+)
2. Script จะเปรียบเทียบเฉพาะ **Sheet แรก** ของแต่ละไฟล์
3. การเปรียบเทียบจะ **ข้ามช่องว่าง (Whitespace)** ที่หัวและท้ายข้อความ
4. หากขนาดไฟล์ไม่เท่ากัน จะเปรียบเทียบเฉพาะส่วนที่ซ้อนทับกัน
